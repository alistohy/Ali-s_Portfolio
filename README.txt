# Ali Stohy DevOps Portfolio

Files included:
- index.html
- style.css
- script.js

How to use:
1. Extract the ZIP file.
2. Open `index.html` in your browser.
3. Edit the text, links, and project content as needed.

Notes:
- This portfolio uses CDN links for Tailwind CSS and GSAP.
- Internet is needed the first time for external libraries to load.
- You can deploy it easily on GitHub Pages, Netlify, or Vercel.
